# Source Sans 3

Unmodified static TrueType fonts from Adobe’s official [Source Sans 3.052R release](https://github.com/adobe-fonts/source-sans/releases/tag/3.052R), release asset [TTF-source-sans-3.052R.zip](https://github.com/adobe-fonts/source-sans/releases/download/3.052R/TTF-source-sans-3.052R.zip). Release tag object: `5d173ba058bda87bcff2bb2d53b9d2c59d440ff6`; resolved source commit: `ed1808970eb3c7301c9a523bee26473ba0bb62fa`.

Only `TTF/SourceSans3-Regular.ttf`, `TTF/SourceSans3-Semibold.ttf` and `TTF/SourceSans3-Bold.ttf` were extracted, unchanged. Their actual PostScript names are `SourceSans3-Regular`, `SourceSans3-Semibold` and `SourceSans3-Bold`; OS/2 weights are 400, 600 and 700. None has variation axes. No variable-font instance or synthetic weight is used.

The original [SIL OFL 1.1 license](OFL.txt) is copied from [the pinned release source](https://github.com/adobe-fonts/source-sans/blob/ed1808970eb3c7301c9a523bee26473ba0bb62fa/LICENSE.md). Only line endings and trailing whitespace are normalized; license wording is preserved. Keep it with redistributed font files. Generated PDFs contain embedded subsets. SHA-256 font hashes and the common glyph intersection are regenerated by `npm run fonts:coverage` into `app/pdf/font-coverage.js`; tests verify both against the actual fonts.

The renderer exposes Regular/Bold through `SourceSans3`, and the distinct Semibold family through `SourceSans3Semibold`. The required italic API slots map to upright files; italics are not a supported formatting feature.
